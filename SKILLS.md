# Brainiac Public Skill Catalog

This catalog distills a large personal skill library into 50 reusable public
skills. Each skill is intentionally broad enough to be useful across Codex,
Claude Code and Grok Build, while staying small enough to maintain.

## Core Agent Workflow

1. **agent-routing**  
   Decide which instructions, tools, skills and project context apply.

2. **context-intake**  
   Read the local project shape before acting.

3. **task-planning**  
   Break work into one useful increment with clear acceptance criteria.

4. **focused-implementation**  
   Make scoped changes without unrelated refactors.

5. **verification-loop**  
   Run relevant checks, interpret failures and fix regressions.

6. **handoff-summary**  
   Explain what changed, what was verified and what remains.

7. **memory-hygiene**  
   Avoid loading old projects or storing sensitive context without consent.

8. **multi-agent-coordination**  
   Keep Codex, Claude Code and Grok Build aligned around one shared brain.

## Code And Architecture

9. **codebase-onboarding**  
   Map project structure, conventions, dependencies and entry points.

10. **code-review**  
    Find bugs, regressions, missing tests and risky behavior.

11. **refactoring**  
    Simplify code while preserving behavior.

12. **architecture-decisions**  
    Capture important choices, alternatives and tradeoffs.

13. **api-design**  
    Design clear interfaces, endpoints, contracts and error behavior.

14. **frontend-engineering**  
    Build usable web interfaces with responsive layout and clean state.

15. **backend-engineering**  
    Implement services, APIs, persistence and application logic.

16. **database-design**  
    Model tables, indexes, migrations and data access patterns.

17. **systems-programming**  
    Work with C, build systems, memory, processes and low-level debugging.

18. **performance-tuning**  
    Diagnose bottlenecks and improve runtime, bundle, query or resource cost.

## Testing And Quality

19. **test-strategy**  
    Choose practical unit, integration, e2e and regression coverage.

20. **test-generation**  
    Add focused tests for changed behavior and edge cases.

21. **sandbox-testing**  
    Run checks in temporary or isolated locations.

22. **browser-testing**  
    Validate web behavior with Playwright, Cypress or browser tooling.

23. **qa-triage**  
    Reproduce bugs, isolate cause and propose a reliable fix.

24. **release-readiness**  
    Check whether a change is safe to ship.

25. **accessibility-review**  
    Catch practical accessibility issues in UI flows.

## Security And Compliance

26. **security-baseline**  
    Check for unsafe input handling, leaks, injection and auth mistakes.

27. **secrets-management**  
    Prevent secrets from entering files, logs, memory or commits.

28. **dependency-security**  
    Review dependency risk, updates and vulnerable packages.

29. **threat-modeling**  
    Identify assets, actors, trust boundaries and abuse paths.

30. **privacy-review**  
    Minimize data collection and avoid unnecessary exposure.

31. **compliance-readiness**  
    Prepare evidence and controls for GDPR, SOC2, ISO, NIST or similar needs.

## DevOps And Operations

32. **git-workflow**  
    Stage deliberately, write human commits and avoid unsafe history changes.

33. **ci-cd**  
    Design and debug build, test and deploy pipelines.

34. **container-workflow**  
    Work with Docker, Compose and containerized development.

35. **kubernetes-ops**  
    Diagnose workloads, services, ingress, scaling and cluster issues.

36. **infrastructure-as-code**  
    Use Terraform, Ansible or similar tools with reviewable changes.

37. **observability**  
    Use logs, metrics, traces and dashboards to understand systems.

38. **incident-response**  
    Triage production issues, communicate status and reduce recurrence.

## Cloud And Data

40. **azure-architecture**

41. **edge-platforms**

43. **analytics**

## Product, Docs And Communication

    Clarify users, jobs, scope, value and tradeoffs.

46. **technical-writing**

47. **decision-logging**

49. **research-synthesis**
